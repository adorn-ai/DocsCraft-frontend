## 3. Authentication

The MagaBands API uses **OAuth 2.0** for authentication. To access protected endpoints, you must include a valid access token in the `Authorization` header of your requests.

### Authentication Flow:
1. **Obtain an Access Token**:
   - Register your application in the MagaBands Developer Portal.
   - Use the `/oauth/token` endpoint to exchange your client credentials for an access token.

2. **Include the Token in Requests**:
   ```http
   Authorization: Bearer YOUR_ACCESS_TOKEN
   ```

### Example Token Request:
```http
POST /oauth/token HTTP/1.1
Host: api.magabands.com
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET
```

### Token Response:
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

## 4. Endpoints

### 4.1. User Management

#### `POST /users/register`
Register a new user.

**Request Body**:
```json
{
  "email": "user@example.com",
  "password": "securePassword123",
  "name": "John Doe",
  "role": "fan|band_member|organizer"
}
```

**Responses**:
- `201 Created`: User successfully registered.
  ```json
  {
    "id": "usr_12345",
    "email": "user@example.com",
    "name": "John Doe",
    "role": "fan"
  }
  ```
- `400 Bad Request`: Invalid input data.
- `409 Conflict`: Email already registered.

---

#### `POST /users/login`
Authenticate a user and return an access token.

**Request Body**:
```json
{
  "email": "user@example.com",
  "password": "securePassword123"
}
```

**Responses**:
- `200 OK`: Login successful.
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",
    "expires_in": 3600
  }
  ```
- `401 Unauthorized`: Invalid credentials.

---

#### `GET /users/{user_id}`
Retrieve user details.

**Parameters**:
- `user_id` (path, required): The ID of the user.

**Responses**:
- `200 OK`: User details retrieved.
  ```json
  {
    "id": "usr_12345",
    "email": "user@example.com",
    "name": "John Doe",
    "role": "fan",
    "created_at": "2023-10-01T12:00:00Z"
  }
  ```
- `404 Not Found`: User not found.

### 4.2. Band Management

#### `POST /bands`
Create a new band.

**Authentication**: Required (role: `band_member` or `organizer`).

**Request Body**:
```json
{
  "name": "The Rockers",
  "genre": "Rock",
  "description": "A high-energy rock band from New York.",
  "members": ["usr_12345", "usr_67890"]
}
```

**Responses**:
- `201 Created`: Band created successfully.
  ```json
  {
    "id": "band_12345",
    "name": "The Rockers",
    "genre": "Rock",
    "description": "A high-energy rock band from New York.",
    "members": ["usr_12345", "usr_67890"],
    "created_at": "2023-10-01T12:00:00Z"
  }
  ```
- `400 Bad Request`: Invalid input data.
- `401 Unauthorized`: Authentication failed.
- `403 Forbidden`: User lacks required permissions.

---

### 4.3. Event Management

#### `POST /events`
Create a new event.

**Authentication**: Required (role: `organizer` or `band_member`).

**Request Body**:
```json
{
  "name": "Rock Concert 2023",
  "description": "An amazing rock concert featuring The Rockers.",
  "band_id": "band_12345",
  "venue": "Madison Square Garden",
  "date": "2023-12-15T20:00:00Z",
  "ticket_price": 50.00
}
```

**Responses**:
- `201 Created`: Event created successfully.
  ```json
  {
    "id": "evt_12345",
    "name": "Rock Concert 2023",
    "description": "An amazing rock concert featuring The Rockers.",
    "band_id": "band_12345",
    "venue": "Madison Square Garden",
    "date": "2023-12-15T20:00:00Z",
    "ticket_price": 50.00,
    "created_at": "2023-10-01T12:00:00Z"
  }
  ```
- `400 Bad Request`: Invalid input data.
- `401 Unauthorized`: Authentication failed.
- `403 Forbidden`: User lacks required permissions.

---

#### `GET /events/{event_id}`
Retrieve event details.

**Parameters**:
- `event_id` (path, required): The ID of the event.

**Responses**:
- `200 OK`: Event details retrieved.
  ```json
  {
    "id": "evt_12345",
    "name": "Rock Concert 2023",
    "description": "An amazing rock concert featuring The Rockers.",
    "band_id": "band_12345",
    "venue": "Madison Square Garden",
    "date": "2023-12-15T20:00:00Z",

    "created_at": "2023-10-01T12:00:00Z"

  ```

---

#### `GET /events`
Search for events with optional filters.

**Parameters**:
- `band_id` (query, optional): Filter events by band ID.
- `date` (query, optional): Filter events by date (YYYY-MM-DD).
- `venue` (query, optional): Filter events by venue name.

**Responses**:
- `200 OK`: List of events matching the criteria.
  ```json
  [
    {
      "id": "evt_12345",
      "name": "Rock Concert 2023",
      "band_id": "band_12345",
      "venue": "Madison Square Garden",
      "date": "2023-12-15T20:00:00Z"
    }
  ]
  ```
