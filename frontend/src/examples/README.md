## Project Title and Description

**Project Title:** Reddit Sentiment Analysis Pipeline

**Description:** This project extracts Reddit posts from various Kenyan subreddits, transforms and cleans the text, loads data into a PostgreSQL database, and uses a machine learning model to perform sentiment analysis for various topics such as politics and sports. The pipeline is orchestrated using Apache Airflow DAGs and containerized with Docker Compose. It also integrates Prometheus and Grafana for monitoring and visualization.

## Features

- **Data Extraction:** Collects Reddit posts using the praw API.
- **Data Transformation:** Cleans text and computes sentiment scores using VADER (NLTK).
- **Data Loading:** Stores structured results into a PostgreSQL database.
- **Orchestration:** Managed with Apache Airflow DAGs.
  - `reddit_dag`: Fetches and stores fresh Reddit posts.
  - `analysis_dag`: Performs sentiment analysis after `reddit_dag` completes.
- **Monitoring:** Grafana dashboards for real-time insights and Prometheus for metrics and health monitoring.
- **Alerts:** Email notifications on DAG failures via SMTP.

## Installation Instructions

### 1. Clone this repository

```bash
git clone https://github.com/dkkinyua/RedditSentimentAnalysis
```

### 2. Setup Python environment and install dependencies

```bash
python3 -m venv myenv
source myenv/bin/activate
pip install -r requirements.txt
```

### 3. Run Docker services

```bash
docker compose up --build
```

Run with `--build` flag to build our custom Dockerfile image. Access the Airflow webserver at `http://localhost:8080`.

## Usage Examples

1. **Extracting Reddit posts:** The `reddit_dag` fetches the latest posts from the specified subreddits and stores them in the PostgreSQL database.

2. **Sentiment Analysis:** The `analysis_dag` retrieves the stored posts, performs sentiment analysis using the VADER sentiment analysis tool, and stores the results back in the database.

3. **Monitoring:** The pipeline integrates Prometheus and Grafana for monitoring. You can access the Grafana dashboard at `http://localhost:3000` to view real-time insights and metrics.
